Sync across devices

Your progress is saved to a private Gist on your own GitHub account — not in this public repo, and not on anyone else's server. Paste the token once per device; this browser remembers it.

  1. Open github.com/settings/tokens → Generate new token (fine-grained).
  2. Set an expiry you're happy with, then under Account permissions set Gists to Read and write. Leave everything else alone.
  3. Generate, copy the token, paste it below.
Not syncing — progress stays on this device only.
The token is stored in this browser's local storage so the page can save on your behalf. It only has access to your Gists — nothing else on your account. On a shared or public computer, hit Disconnect when you're done.
